PC & Mac File Transfer Guide

Transfer files between Android and PC or Mac in your browser.

Install LocalHub only on your Android phone or tablet. Open the local address in Chrome, Edge, or Safari on Windows or macOS to send and download files directly over your local network.

Download on Google Play Jump to troubleshooting

Before you start: network requirements

  • Connect your Android device and Windows PC or Mac to the same Wi-Fi network, or connect the computer to your phone's temporary hotspot.
  • Make sure the router allows local device-to-device access. Public, hotel, campus, or guest Wi-Fi networks often enable AP/client isolation that blocks local connections.
  • Use only on a trusted local network. Local HTTP traffic is not encrypted, even when an optional access password is enabled.
01

Start sharing on Android

Open LocalHub and tap Start Sharing. Fresh installs keep sharing off until you start it manually. LocalHub displays your active local URL (for example, http://192.168.1.10:9091—always use the address shown in the app).

02

Open the URL on PC or Mac

Type the local address into Chrome, Edge, or Safari on your computer. No receiver app or login is required. If you enabled an access password in LocalHub Settings, enter it when prompted.

03

Send files in both directions

Computer to Android: drag and drop or pick files on the web page—saved files appear in File Management and Downloads/LocalHub. Android to Computer: import or share files into LocalHub (or Media Library), then click Download directly in your desktop browser.

04

Stop sharing when finished

Tap Stop Sharing in the app (or let the auto-stop timer expire). Stopping immediately closes the local server port and ends browser access.

Free vs. one-time Premium limits

Free

  • Two-way local file transfer through a compatible browser
  • Single-file browser upload and media import up to 50 MiB per file
  • Browse, play, and individually download shared media in your browser

Premium (one-time purchase)

  • Larger file uploads beyond the 50 MiB free limit
  • WebRTC screen and camera live streaming to nearby browsers
  • Cross-device text sharing, custom access password, custom port, and batch media ZIP download

Troubleshooting connection issues

The browser cannot open the local address (timeout or unreachable)
Confirm LocalHub shows Online and both devices are on the exact same Wi-Fi (not Guest Wi-Fi or cellular data). Temporarily pause VPNs on either device. If your router enforces AP isolation, switch to Android's local hotspot and reconnect the PC/Mac.
The browser forced HTTPS and failed to load
LocalHub runs a local HTTP server. Make sure the address bar starts with http:// (not https://) and includes the exact port number shown in LocalHub.
Access password was changed while a browser tab was already open
Existing protected requests with the old password return 401. Use the on-page Retry / Play / Select action to enter the new password without needing to restart LocalHub.
Upload rejected for a large file
Free tier uploads are capped at 50 MiB per file. Check available storage space on Android, or unlock Premium if you need larger transfers.
